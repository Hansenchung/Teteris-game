# JS Tetris 🕹️

A feature-rich, responsive web-based Tetris game built using vanilla JavaScript, HTML5 Canvas, and CSS. 

## ✨ Features

* **Classic Gameplay Mechanics:** Full implementation of standard Tetris rules, scoring, level progressions, and line clears.
* **Modern Enhancements:**
  * **Hold Piece:** Save a piece for later use by pressing **C** or **Shift**[cite: 1, 3].
  * **Next Piece Preview:** Anticipate your upcoming piece[cite: 1, 3].
  * **Ghost Piece:** Easily see where your piece will land with the translucent drop guide[cite: 1].
  * **Super Rotation System (SRS):** Wall kicks included for smooth rotations[cite: 1].
  * **Random Bag Generator:** Fair piece distribution using the 7-bag randomizer system[cite: 1].
* **Audio Feedback:** Built-in web audio synthesizer for movement, rotation, drops, and clears without external audio assets[cite: 1].
* **High Score Tracking:** LocalStorage integration to persistently save your best score[cite: 1].
* **Responsive Touch Controls:** Built-in on-screen buttons for mobile and touch-screen devices[cite: 2, 3].
